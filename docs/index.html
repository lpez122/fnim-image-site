Image dataset, CNN, and stimulus-set tabs

This website provides public access to a representative subset of the lab’s image dataset, related CNN analyses, and the curated visual-semantic stimulus set. Visitors can browse public dataset thumbnails, compare full-archive CNN and semantic structure, and inspect a separate stimulus-set explorer that contrasts multiple CNN visual models with GloVe semantic similarity.

What the site does now

Full category coverage

The website can represent the full dataset structure while only publishing a small thumbnail subset for each category.

Dataset tab

Search, sort, and filter categories while inspecting copied public sample images without exposing the full-resolution archive.

CNN tab

Compare VGG16, AlexNet, ConvNeXt V2, and Semantic (GloVe) using nearest neighbors, 2D projections, and an advanced clustered matrix view.

Stimulus-set tab

Explore the curated within-category and between-category triplets with VGG16, AlexNet, ConvNeXt V2, and Semantic (GloVe) views.

Useful now

Public thumbnails for every category, capped at 1-3 images per category.

Category-level Excel, CSV, and JSON exports built from the full image dataset.

A stimulus-set explorer that compares multiple CNN models and semantic similarity over the curated triplets.

A user-facing CNN explorer that compares visual backbones and semantic embeddings without defaulting to raw matrices.
